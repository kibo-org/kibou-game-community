# Security And Privacy

Report vulnerabilities privately to info@yadocareer.jp. Do not attach real user
data, credentials, personal documents or detailed exploit material to a public
issue. Describe the affected area and reproduction using fictional data.
No promise of a bounty or response SLA is made.

This project has no production data/API access. Simulated applications and Host
reviews are local fiction, not trust decisions. No arbitrary message input is offered.
Please report additions of telemetry, unexpected network traffic, unsafe asset
loading or code that attempts to read non-community local storage.

Never add repository/org secrets or a production Environment to this repository.
Read-only CI must use hosted isolated runners. This repository is public: every
Issue, attachment, PR and commit is visible to anyone. The previous private
history remains in a separate private archive and must not be imported here.
If a credential is ever committed, revoke it before removing history; do not
assume deletion or a clean export makes an exposed credential safe again.
